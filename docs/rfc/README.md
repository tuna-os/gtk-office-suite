# RFCs

An **ADR** (`docs/adr/`) records a decision that has been taken. An **RFC**
here records a design that has *not* been taken yet: a proposal written down
so it can be argued with before anyone writes the code.

An RFC should make its own rejection easy. That means stating the constraints
it must satisfy, the options it considered, what it would cost, and what
evidence would settle the open questions — not advocating for a conclusion.
When an RFC is accepted, the decision moves to an ADR and the RFC keeps its
status line as the record of the reasoning.
