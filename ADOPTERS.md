## Why GTK Office Suite?

If you're considering GTK Office Suite, here's what we offer:

- **Pure Rust + GTK4**: Native GNOME application with modern UI patterns and accessibility features
- **Measured Format Parity**: Deterministic screenshot-based CI gates ensure document fidelity against LibreOffice
- **Free & Open Source**: GPLv3 license; full source code transparency
- **Flatpak Distribution**: Containerized, runs on any Linux distribution
- **Headless CLI**: Batch document conversion without GUI (roadmap item #368)
- **Extensible Architecture**: WASM plugin runtime + IPC extensions planned (roadmap item #391)
