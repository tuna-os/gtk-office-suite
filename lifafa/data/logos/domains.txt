# Sender domains that get a bundled brand logo (see README.md and
# tools/fetch-logos.py). One per line: the registrable domain, optionally
# followed by an explicit pick, "gilbarbara:<file>.svg", "simple:<slug>" or
# "brand:<id>" (one of the marks in data/brands/),
# when the automatic match is wrong or missing. Lines starting with # are
# comments.
#
# Mailbox hosts (gmail.com, outlook.com, icloud.com, yahoo.com, proton.me and
# the rest) are listed below for the provider marks, but src/services/logo.rs
# refuses a sender logo for them: an address there belongs to a person, not the
# provider.
#
