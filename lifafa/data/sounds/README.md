# New-mail sounds

The built-in sounds offered under Settings → General → Sound for new mail.
They are GNOME's alert sounds, taken unmodified from
[GNOME Settings](https://gitlab.gnome.org/GNOME/gnome-control-center)
(`panels/sound/sounds/`, installed as
`/usr/share/sounds/gnome/default/alerts/`), and are distributed under that
project's licence, the GNU General Public License v2.0 or later.

| File | Name in Settings |
| --- | --- |
| `click.ogg` | Click |
| `hum.ogg` | Hum |
| `string.ogg` | String |
| `swing.ogg` | Swing |

`resources/sounds.gresource.xml` embeds them in the binary.
